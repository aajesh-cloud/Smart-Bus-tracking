# Smart Bus Tracking System

A real-time college bus tracking system built with the MERN stack (MongoDB, Express, React, Node.js) and Socket.IO.

## Project Status
🚧 In active development — college project

## Tech Stack
- **Backend:** Node.js, Express, MongoDB (Atlas), Mongoose, Socket.IO, JWT
- **Passenger Frontend:** React, Vite, React Router, Leaflet (OpenStreetMap)
- **Driver App:** React, Vite, Browser Geolocation API
- **Real-time:** Socket.IO (bidirectional live location broadcasting)

## Applications
| Folder | Purpose |
|---|---|
| `backend/` | REST API + WebSocket server |
| `frontend/` | Passenger-facing website (live map, search, notifications, admin dashboard) |
| `mobile-driver/` | Driver-facing web app (trip controls, GPS sharing) |
